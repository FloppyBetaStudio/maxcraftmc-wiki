## 前言

您好！MaxCraft服务器欢迎你的到来！  

你刚刚进入服务器时，或许会产生一些疑问。为了帮助你解答这些疑问，我们特意编写了这份《新玩家指南》。

指令中的尖括号表示需要替换的参数，不要输入尖括号本身。例如，假设你的临时示例密码是 `示例密码-A7m!`，注册指令应写成 `/register 示例密码-A7m! 示例密码-A7m!`，登录指令应写成 `/login 示例密码-A7m!`。请勿在实际账号中使用此示例密码，也不要与其他网站共用密码。

## 账号认证

如果你使用正版登录，请跳过这一部分。

如果你使用离线登录（即盗版Minecraft），请确保你使用的名称没有被任何一个正版玩家使用，同时这个用户名符合正版MC玩家名称规则（例如长度合理，不包含特殊符号）。

## 账号相关问题(离线登录)

离线玩家首次进入服务器后，可以使用下方 `/register` 指令自行注册。如果服务器提示账号已存在、无法注册或需要人工审核，请联系管理员处理，不要反复尝试他人的用户名。

登录插件不会以明文保存密码，而是保存用于校验的密码哈希。哈希并不等同于加密，也不能完全消除泄露风险，因此请设置足够长且独立的密码，不要与邮箱、社交账号或其他服务器共用。

### 注册账号

```
/register <在此处输入密码> <再次输入密码>
```

**注意：两次输入的密码须一致**  

### 登陆账号

```
/login <在此处输入密码>
```

### 修改账号密码

```
/changepassword <新的密码> <新的密码>
```

## 服务器特色玩法

MaxCraftMC 的原版生存服务器在保留原版玩法的同时，加入了一些便利性的玩法改动和特色功能。新玩家入服后建议先了解：

- [服务器特色](/redstone/features/)：商店、持久存档、Carpet 支持、法币经济与安保措施。
- [特殊游戏规则](/redstone/gamerules/)：铁砧合并、矿车速度、潜影盒交互、单人睡觉等与原版不同的机制。

例如潜影盒直接**右键**即可打开（Shift+右键才是放置），单人睡觉即可跳过夜晚，这些与原版操作略有不同，提前了解可以避免困惑。

## 便民指令相关问题

### 玩家间传送

#### 传送至其他玩家

```
/tpa <玩家名>
```

#### 传送其他玩家至自己处

```
/tpahere <玩家名>
```

#### 同意其他玩家的传送请求 

```
/tpaccept
```

#### 取消发出的传送请求 

```
/tpacancel
```

### 其它传送

#### 返回

返回到传送前或死亡时的位置：

```
/back
```

#### 公共传送点

在当前位置设置：

```
/setwarp <传送点名称>
```

传送到公共传送点：

```
/warp <传送点名称>
```

删除公共传送点：

```
/delwarp <传送点名称>
```
